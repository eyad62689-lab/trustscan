## ١. الشخصيتان المرجعيتان لاختبار NFR-13

### ش١ — تاجر جملة وتجزئة لمواد السباكة (مسار كامل)

| البند | القيمة |
|---|---|
| ضريبة القيمة المضافة | مسجل |
| المستخدمون | ١٢ |
| الفروع | ٢ (مستودع لكل فرع) |
| الموظفون | ١٨ |
| العملاء | أفراد ومنشآت |
| الوضع الحالي | إكسل وبرنامج محاسبي قديم |
| الوحدات | ACC، SAL، PUR، INV، EXP، TRS (وTAX تلقائياً) |
| نمط الإجابة | إجابات محددة في الأسئلة الجوهرية، و«لا أعلم» في سؤالين، والموصى به في البقية |

**إجابات محددة:**
- **SAL:**
  - SAL-001: نقدي + آجل.
  - SAL-002: عرض سعر ← فاتورة.
  - SAL-003: ١٥ يوماً، ولا يُحوَّل المنتهي.
  - SAL-005: «جملة» و«تجزئة».
  - SAL-006: قائمة أسعار لكل فئة + عروض مؤقتة.
  - SAL-007: موظف المبيعات ٥٪، المدير العام ١٥٪، المالك دون حد؛ لا بيع تحت التكلفة إلا للمالك.
  - SAL-008: الحد يمنع إلا باعتماد.
  - SAL-009: نقدي، و٣٠ يوماً، و٦٠ يوماً.
  - SAL-010: نقد، وبطاقة، وتحويل.
  - SAL-011: «لا أعلم».
  - SAL-013: مندوبون دون عمولة.
  - SAL-018: توصيل بسياراتنا مع تحصيل عند التسليم.
  - SAL-099: «نحتاج فاتورة مختصرة للعملاء النقديين».
- **PUR:**
  - PUR-001: أمر شراء ← استلام ← فاتورة.
  - PUR-002: استيراد أحياناً.
  - PUR-003: توزيع تكاليف الاستيراد حسب القيمة.
  - PUR-007: اعتماد حسب القيمة.
  - PUR-009: مطابقة تمنع السداد إلا باعتماد.
  - PUR-010: استلام جزئي.
  - PUR-013: شراء مركزي.
- **INV:**
  - INV-001: مستودعان.
  - INV-005: تتبع صلاحية لبعض المواد اللاصقة.
  - INV-006: «لا أعلم».
  - INV-008: جرد ربع سنوي.
  - INV-009: تحويل باعتماد.
  - INV-012: حجز نعم.

### ش٢ — منشأة خدمات صيانة تكييف صغيرة (مسار مختصر)

| البند | القيمة |
|---|---|
| ضريبة القيمة المضافة | غير مسجلة |
| المستخدمون | ٢ (المالك والمحاسب) |
| الفروع | ١ |
| الموظفون | ٥ فنيين |
| العملاء | أفراد فقط |
| الوضع الحالي | دفتر يدوي وإكسل |
| الوحدات | ACC، SAL، PUR، INV، EXP، TRS (TAX مخفي) |
| نمط الإجابة | «لا أعلم» في أغلب الأسئلة التفصيلية؛ اختبار لجودة الإجابات الموصى بها والقواعد القياسية |

**إجابات محددة:**
- SAL-001: نقدي فوري فقط.
- SAL-018: الخدمة في موقع العميل دون توصيل بضاعة.
- PUR-001: شراء مباشر بفاتورة دون أمر شراء.
- INV-001: مستودع واحد، وسيارات الفنيين أماكن تخزين.
- INV-010: صرف قطع للفنيين على أوامر الصيانة.
- **بقية الأسئلة:** «لا أعلم».

**معيار الاجتياز (NFR-13):** لكل شخصية، على SAL وPUR وINV:
- فجوات (ب) قرار عمل + (ج) تعارض + (د) غموض = **صفر**.
- فجوات (أ) قيمة ناقصة ≤ ٢ لكل وحدة، وكلها في سجل الافتراضات.

## ٢. قائمة المصطلحات (NFR-07)

### ٢-أ. محظورة مطلقاً — فحص آلي، والنتيجة المقبولة صفر

| المحظور | البديل المعتمد |
|---|---|
| الموديول | الوحدة |
| القسم البرمجي | الوحدة |
| الزبون | العميل |
| المخزن | المستودع |
| الكاش | الصندوق |
| الخزنة | الصندوق |
| الرول | مسيّر الرواتب |
| كشف الرواتب | مسيّر الرواتب |
| التصديق | الاعتماد |
| التقرير النهائي | وثيقة المتطلبات |
| القيمة الافتراضية الصامتة | افتراض مُعلن |
| البائع | المورّد (من يُشترى منه)، أو موظف المبيعات (الدور) |

### ٢-ب. تُراجع يدوياً — كلمات لها استعمال مشروع في سياق آخر

| الكلمة | المحظور منها | المسموح |
|---|---|---|
| المنتج / المادة | بمعنى الصنف | — |
| الحساب | بمعنى المستخدم | الحساب المحاسبي أو البنكي |
| المسمى الوظيفي | بمعنى الدور | وصف الوظيفة في الموارد البشرية (مؤجلة) |
| الموافقة | بمعنى الاعتماد | موافقة العميل على عرض سعر |
| الوثيقة | لغير وثيقة المتطلبات | — |
| الجهة / المؤسسة | بمعنى الكيان | الجهة الحكومية؛ المؤسسة نوعاً قانونياً |
| الموقع | بمعنى الفرع | الموقع الجغرافي؛ «الفروع والمواقع» جمعاً |
| السلفة / العهدة | الخلط بينهما | كلٌّ بتعريفه في المعجم |

## ٣. قائمة الحياد (NFR-08)

### ٣-أ. فحص آلي — النتيجة المقبولة صفر في الواجهة والبنك والوثيقة

| الفئة | الأسماء |
|---|---|
| أنظمة عالمية (لاتينية، دون حساسية لحالة الأحرف) | SAP، Oracle، NetSuite، Microsoft Dynamics، Business Central، Odoo، Zoho، QuickBooks، Xero، Sage، Epicor، Infor، Acumatica، Foodics، Daftra، Qoyod، Wafeq، Rewaa، SMACC، Dafater، Medad، Shumoul، Sajaya |
| أنظمة بالعربية (غير ملتبسة) | ساب، أوراكل، نتسويت، أودو، زوهو، كويك بوكس، دفترة، فودكس، سماك، دفاتر (اسم علم بأل التعريف فقط حين يسبق «نظام» أو «برنامج») |
| الأسعار | أي رمز عملة أو كلمة «ريال» مقرونة بكلمة «اشتراك» أو «شهرياً» أو «سعر الباقة» |

### ٣-ب. تُراجع يدوياً — أسماء أنظمة تطابق كلمات عربية شائعة

قيود (اسم نظام، ومصطلح محاسبي مشروع)، وافق، رواء، مداد، شمول، زيرو، سجايا. تُرفض فقط حين تأتي اسمَ منتج.
