#### 3.1.2 سير العمل

1. **القيد اليدوي:** المحاسب يُنشئ مسودة متوازنة ← يرسلها ← «بانتظار الاعتماد» ← المالك يعتمد فيُرحَّل، أو يرفض فيعود للمحاسب (STD-GEN-29، ACC-008).
2. **القوالب المتكررة وجداول التوزيع:** المحاسب يُنشئ القالب ← اعتماد المالك مرة عند التفعيل ← تنبيه المحاسب قبل الترحيل بيوم ← توليد القيد آخر يوم في الشهر (الثابت يُرحَّل آلياً، والمتغير قيد يدوي مسودة يُكمله المحاسب ويعتمده المالك) (STD-ACC-11). وجدول التوزيع ينشأ آلياً من المستند الموسوم «مدفوع مقدماً» ويفعّله المحاسب دون اعتماد (STD-ACC-12).
3. **الإقفال الشهري:** المحاسب يُنشئ «طلب إقفال فترة» بقائمة الفحص ← المالك يعتمد (مع مخرج نقل المعلّق إلى الفترة التالية) ← قفل التاريخ، وقيد إقفال السنة عند آخر فترة (STD-ACC-07، 08، 09). وإعادة الفتح بطلب مسبَّب يعتمده المالك.
4. **الافتتاح:** عدّ النقد والمخزون (ومنه سيارات الفنيين) بعد انتهاء عمل اليوم السابق للتشغيل ← المحاسب يُعدّ القيد الافتتاحي ومسودات التفاصيل وكشف المطابقة ← المالك يعتمد القيد والكشف خطوة واحدة، فتنفذ التفاصيل آلياً (STD-GEN-61، STD-ACC-10).

#### 3.1.3 حقول البيانات

بطاقة الحساب، والقيد، وسطر القيد: جداول STD-ACC-04 (أ) و(ب) و(ج) كما هي، بعد إسقاط: «الاسم بالإنجليزية» إن كانت GEN-007 «العربية فقط»، و«تصنيف التدفق النقدي» (ACC-006 بلا قائمة التدفقات)، و«أبعاد ACC-004» (لا حاجة). ويبقى «تصنيف وعاء الزكاة» (ACC-011 = «نعم»). وقائمة «حساب مراقبة لوحدة» تتضمن القيمة «الضريبة» **[تسرّب ضريبي — C2-ش٢-ACC-01]**.

#### 3.1.4 قواعد العمل

- «لا أبعاد تحليل في القيود» (ACC-004 = «لا حاجة»).
- القواعد القياسية السارية، بمعرّفاتها ونصوصها كما في `10-acc.md` ومصدر «قياسي»: STD-ACC-04، STD-ACC-05، STD-ACC-06، STD-ACC-07، STD-ACC-08، STD-ACC-09 (الصف «منشأة فردية + حساب جارٍ» ← «جاري المالك»)، STD-ACC-10 (الحالة الثانية: ورق وإكسل)، STD-ACC-11، STD-ACC-12 (البندان ١ و٢)، STD-ACC-15. ولا يسري: STD-ACC-01 (أساس الاستحقاق)، STD-ACC-02، STD-ACC-03.
- **تسرّب ضريبي في نصوص تُكتب كما هي:** STD-ACC-06 (٣) «وحسابات الضريبة تُعالج وفق قواعد وحدة TAX»، وSTD-ACC-07 (٥) البند الأخير «لا يرفع فتح الفترة المحاسبية قفل الإقرار الضريبي المقدَّم (STD-TAX-05 (٥)…)». **[إحالة معلّقة — C2-ش٢-ACC-01]**

#### 3.5.2 سير العمل

1. **سند المصروف:** المحاسب يُنشئ ← حتى 500 ينفذ بيده (مسؤول الصندوق، أو المحاسب للحساب البنكي)؛ وأكبر من 500 «بانتظار الاعتماد» ← المالك ← «معتمد» ← «منفَّذ» (STD-GEN-29، STD-GEN-33).
2. **العهدة الدائمة:** «صرف عهدة مصروفات» جديد يُنشئه المحاسب ← اعتماد TRS-008 (ما يُنشئه المحاسب يعتمده المالك، ROL-005) ← «منفَّذ» بيد مسؤول الصندوق ← سطور مصروفات مسودة على العهدة ← تسوية شهرية يُدخلها المحاسب ← EXP-009 بمجموع المقبول ← «معتمد» ← استكمال آلي «معتمد» ← «منفَّذ».
3. **العهدة المؤقتة:** صرف (TRS-008) ← تسوية خلال 7 أيام ← المتبقي «توريد عهدة» (TRS)، والزيادة «رد زيادة مصروفات» آلياً (STD-EXP-09) ← إقفال السجل عند رصيد صفر. وبعد مهلة ثانية: سطر «نقص عهدة» باعتماد المالك (STD-EXP-02 (٥)).

#### 3.6.2 سير العمل

1. **سند الصرف العام:** المحاسب يُنشئ ← «بانتظار الاعتماد» ← المالك (لأن المُنشئ المحاسب، ROL-005) ← «معتمد» ← «منفَّذ» بيد المحاسب (مسؤول الصندوق، أو للحساب البنكي).
2. **إيداع نقد الصندوق:** المحاسب يرسل ← «نقد في الطريق» ← «مستلم» بتأكيده أو بمطابقته في الكشف.
3. **إقفال الصندوق اليومي:** عدّ أعمى ← «إقفال صندوق» معتمد ← الفرق مسودة «تسوية فرق نقدي» ← المالك ← «معتمد».
4. **التحويل الوارد:** سند قبض «بانتظار تأكيد التحويل» ← المحاسب يؤكد أو يُطابَق ← «صادر».
5. **البطاقات:** مبلغ البطاقة إلى الحساب الوسيط ← «تسوية مبالغ بطاقات» يومية من سطر الكشف ← «معتمد».
6. **المطابقة الشهرية:** رفع الملف ← اقتراح آلي (3 أيام عمل) ← قبول المحاسب ← «مكتملة».
7. **توريد عهدة تحصيل الفني:** يسجّله المحاسب (مسؤول الصندوق) بالمعدود؛ والتوريد النهائي ينشئ الباقي «تسوية فرق نقدي» (STD-TRS-03).
