**أولوية المتطلبات (م-3):** الأولوية الافتراضية لكل متطلب = أولوية وحدته في SCP-001. لم تُذكر أولويات الوحدات في ملف الشخصية، فطُبّق الموصى به في SCP-001: SAL = «ضروري من اليوم الأول». أما PUR فلا ينص الموصى به على أولويتها، فتُركت «غير محددة» (انظر فج-01).

**تصنيف المصدر:** «إجابة» = خيار صريح من المستخدم؛ «إجابة (الموصى به)» = المستخدم قال صراحة «الموصى به» لهذا السؤال؛ «افتراض» = «لا أعلم» أو بلا إجابة؛ «نص حر» = XXX-099. (التمييز بين النوعين الأولين غير محسوم في المواصفة — انظر فج-02).

**وسم [يحتاج تحقق]:** ما ورد في نص البنك بهذا الوسم نُقل كما هو، ويُجمع في قائمة التحقق للمنفّذ (4.8) لا في الفجوات.

### 3.1.2 سير العمل

**أ. البيع بعرض سعر (SAL-002، SAL-003، SAL-019، SAL-007، SAL-008):**
1. يُنشئ البائع عرض سعر للعميل؛ يُسعَّر كل سطر وفق الأسبقية في SAL-R006c، ويُطبَّق الخصم ضمن حد الدور (SAL-R007a).
2. إن تجاوزت قيمة العرض 50,000 ريال أو تجاوز الخصم حد الدور ← حالة «بانتظار الاعتماد» ← اعتماد «المدير» (SAL-R019a، SAL-R007b).
3. يُرسَل العرض للعميل؛ صلاحيته 15 يوماً (SAL-R003a).
4. بعد انتهاء الصلاحية ← حالة «منتهي»، ولا يُحوَّل إلا بتجديد (SAL-R003b).
5. يُحوَّل العرض الساري إلى فاتورة دون إعادة إدخال (SAL-R002).
6. إن كانت الفاتورة آجلة ← فحص حد الائتمان؛ عند التجاوز ← منع إلا باعتماد استثنائي (SAL-R008)، ويُحسب تاريخ الاستحقاق (SAL-R009b).
7. تُقفل الفاتورة بعد الإصدار (SAL-R012a).

**ب. التسليم والتحصيل عند التسليم (SAL-018):** إنشاء إذن تسليم «جاهز» ← «خرج» ← «سُلِّم»؛ ويُسجَّل المبلغ المحصَّل عهدةً على السائق (SAL-R018a، SAL-R018b). موضع إذن التسليم من التسلسل غير محسوم (فج-05).

**ج. التحصيل (SAL-010، SAL-011):** سند قبض بإحدى الطرق الثلاث ← توزيع تلقائي على الأقدم مع إمكانية التعديل ← تحديث حالة الفاتورة (غير مدفوعة / مدفوعة جزئياً / مدفوعة).

**د. المرتجع (SAL-012، SAL-019):** إنشاء مرتجع مرتبط بالفاتورة الأصلية خلال 7 أيام ← «بانتظار الاعتماد» ← اعتماد «المدير» ← تحديث المخزون ورصيد العميل ← رد نقدي أو رصيد للعميل.

### 3.2.2 سير العمل

**أ. الشراء المحلي (PUR-001، PUR-007، PUR-008، PUR-013):**
1. يُنشئ المستخدم أمر شراء على مستوى الإدارة (شراء مركزي).
2. يُوجَّه للاعتماد بحسب قيمته: ≤ 5,000 مسؤول المشتريات؛ 5,001–50,000 المدير العام؛ > 50,000 المالك. الرفض يعيده للمُنشئ؛ التذكير بعد 24 ساعة.
3. بعد الاعتماد يُرسل للمورّد.
4. الاستلام كلياً أو جزئياً، مع رصيد متبقٍ؛ وإمكانية إقفال الأمر يدوياً (PUR-R010).
5. تسجيل فاتورة المورّد ← مطابقة ثلاثية؛ عند الفرق ← «فرق يحتاج معالجة» ومنع السداد إلا باعتماد (PUR-R009).
6. التحويل للفروع عبر مستند التحويل المخزني (INV-009).

**ب. الاستيراد (PUR-002، PUR-003):** أمر شراء بعملة أجنبية ← استلام ← فاتورة المورّد ← مستند «تكاليف الشحنة» ← توزيع التكاليف حسب القيمة ← تحديث تكلفة الأصناف.

**ج. السداد (PUR-012):** سند صرف واحد لعدة فواتير بتحويل بنكي ← اعتماد وفق TRS-008 ← التنفيذ.

**د. المرتجع (PUR-011):** مرتجع مرتبط بالفاتورة ← تحديث المخزون ← رصيد لصالح المنشأة لدى المورّد.
